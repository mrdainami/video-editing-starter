# Connect Borumi

Install [Borumi](https://borumi.com/install/), open your recording and enable MCP in the app's AI settings. Keep the app open.

The agent should read the current app-provided MCP instructions and register the local process for this machine. On a standard macOS installation:

```text
Transport: stdio
Command: /Applications/Borumi.app/Contents/MacOS/borumi
Arguments: mcp
```

For other platforms, use the executable path supplied by the installed app. Read the current client's MCP help before writing its registration; preserve unrelated servers. Reconnect the agent if required.

Verify with the Borumi MCP guides and project list. Identify the intended source recording and separate working project. Confirm that its transcript is ready before cutting. If transcription is pending or unavailable, use the app's supported transcription route and report the state.

Check export access in the app when preparing the first review export.

[Borumi help](https://borumi.com/help/introduction/quick-start/)

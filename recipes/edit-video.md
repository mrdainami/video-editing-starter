# Edit a video

Use the selected `videos/<video-name>/` folder for all paths below. Shared skills
and tools remain at the workspace root.

1. **Cut:** use `skills/yt-first-cut/SKILL.md` to inspect Borumi's transcript and
   cut through MCP. Show the first cut for review.
2. **Agree visuals:** read the video's brand direction. Suggest graphics/b-roll,
   or use the user's directions. Save the agreed ideas and exact spoken phrases
   in `project/edit-plan.md`.
3. **Build:** use the installed HyperFrames skills in `project/work/<segment>/`.
   Keep each segment's playback media in its `media/` folder. Use KIE for assets
   if needed; quote paid jobs first and record their IDs immediately. For the
   storyboard method, read `skills/storyboard-method/SKILL.md`.
   Perform media preparation, effects, transitions and audio arrangement in
   HyperFrames. Use its snapshot, preview and render commands for visual review;
   do not introduce standalone processing commands or scripts.
4. **Preview:** render and inspect the segment, then show it to the user. Revise
   when requested. Wait for approval before adding the treatment to Borumi.
5. **Insert:** resolve the spoken anchors against the current Borumi timeline.
   Re-read timeline state inside the transaction and recompute if it changed.
   When an entrance needs a full composite, include the base picture in the
   render and insert as a fullscreen take. Keep speech once.
6. **Finish:** review picture, joins and audio in Borumi, then export to
   `exports/review-v1.mp4`, incrementing revisions. Update `project/STATUS.md`.

Use `recipes/generate-broll.md` or `recipes/audio.md` when that work is needed.
Publishing is separate from exporting a review.

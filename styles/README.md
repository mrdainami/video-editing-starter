# Graphics styles

Each folder here is one style: reusable graphics in one look, each with its own sound effects.

- See what you have: `/styles` (shows each style's `preview.jpg`).
- Use one in a video: `/add-graphics` ("add my vibe graphics to this video").
- Make a new one: `/new-style`. It starts from `_blank/`.
- Your default style is set in `brand/BRAND.md`.

```text
styles/<style>/
  preview.jpg       one image with every graphic (numbered)
  demo.mp4          the style in action (optional)
  STYLE.md          colours, fonts, rules, the list of graphics, sounds
  graphics/         the graphics (HyperFrames): src/ to edit, compositions/ to use
  sounds/           each graphic's sound effects
  assets/           your logo and images used inside the graphics
  references/       what the look was based on
  demo-project/     how demo.mp4 was made (optional)
```

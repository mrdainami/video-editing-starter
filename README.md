# AI Video Editing Starter

A reusable workspace for cutting recordings, adding graphics and B-roll, and keeping each video together.

[Download the starter ZIP](https://github.com/mrdainami/video-editing-starter/releases/latest/download/video-editing-starter.zip)

Unzip it, open the folder in your local AI agent, and follow [START-HERE.md](START-HERE.md).

Works with agents that can read local files, run commands and connect to MCP tools. Borumi handles the edit. HyperFrames makes graphics. KIE supplies optional generated assets.

- `brand/`: your shared brand and tone.
- `skills/`: workspace setup, brand setup, new video, first cut and storyboard instructions.
- `templates/video/`: an empty starting folder for each edit.
- `videos/<video-name>/`: each video's brief, assets, work and exports.

The release ZIP includes a blank `.env`. If you download GitHub's source archive or clone this repository, setup creates it from `.env.example`.

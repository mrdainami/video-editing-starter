# Visual ideas: you say X → show Y

This list decides **what picture** goes with a line. It works with every style; the style pack only decides how it looks.

How to use it:
1. Read the transcript. Mark the key lines (the claim, the problem, the number, the example, the turn).
2. Match each key line to a row below. Fill the graphic with the words and things actually said.
3. Nothing fits? Invent a picture that shows the idea literally, mark it `new idea` in the plan, and ask. Once approved, add a row here.

## Where images come from

- **Brand and tool logos:** Simple Icons (jsDelivr `simple-icons@13.21.0/icons/<name>.svg`), coloured with the brand hex. Save into the video's `assets/logos/`. If a logo is missing there, leave that tool out rather than redraw it.
- **Simple icons (megaphone, play button, tick):** draw them as small inline SVGs in the style's colours.
- **Photos or invented pictures:** generate with KIE (GPT Image 2 or similar). Quote the price and wait for a yes first. Log task IDs in the video's `generations.json`.
- **Screen recordings:** the user's own clip only.
